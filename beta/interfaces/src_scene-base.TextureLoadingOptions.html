    Interface TextureLoadingOptions

    Additional parameters that can be used when loading Images, Spritesheets or Atlases. They allow to automatically handle textures with a file for each language, atlases/spritesheets that need to be updated live when the UiWindowStyle is changed and UI elements that depend on the current UiTheme.

    interface TextureLoadingOptions {
        filenameRoot?: string;
        languageKey?: string;
        uiThemeDependant?: boolean;
        windowStyleDependant?: boolean;

    OptionallanguageKey

    languageKey?: string

    If provided, the languageKey will be checked for compatibility with localized images, or be replaced with "en". In this case, _{languageKey} will be appended to the filename before loading, e.g. "banner_zh-CW.png".

    OptionaluiThemeDependant

    uiThemeDependant?: boolean

    If set to true, will load the filename corresponding to the current UiTheme (and not the other themes). Elements that use these need to have -{uitheme} at the end of their filename, e.g. "window-dark.png", for each theme. This is applied before any language specific postfix (e.g. "image-dark_de.png" is correct, "image_de-dark.png" is not).

    • Defined in src/scene-base.ts:35

    OptionalwindowStyleDependant

    windowStyleDependant?: boolean

    If set to true, will automatically update any object using this texture when the window style is changed. Only works for atlases with keys corresponding to each UiWindowStyle (starting at "0"), or spritesheets.
